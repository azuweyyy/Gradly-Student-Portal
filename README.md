# Gradly-Student-Portal

## a. Project Title & Description
Gradly Student Portal is a student dashboard web application developed for academic purposes. The system provides students with access to academic information, attendance records, assignments, schedules, and profile management through a modern and responsive interface.

## b. Features Included
- Student dashboard overview
- Responsive sidebar navigation
- Student profile page
- Attendance tracking system
- Assignment monitoring section
- Subject information display
- Interactive charts and tables
- Dark mode interface
- Dummy login validation

## c. Instructions to Test Login
Student Number:
- Must contain exactly 10 numbers

Password:
- Must contain:
  - Uppercase letter
  - Lowercase letter
  - Number
  - Minimum 8 characters

Example:
Student No: 2023123456
Password: Student123

Steps:
1. Open the login page.
2. Enter a valid student number and password.
3. Click the Login button.
4. User will be redirected to the dashboard page.
